# 🌤 iOS Weather App (SwiftUI)

A sleek, responsive weather application built using **SwiftUI** that provides real-time weather updates and forecasts using the [WeatherAPI](https://www.weatherapi.com/). The app follows the **MVVM architecture**, utilizes **MapKit** for dynamic maps, and supports **CoreLocation** to fetch weather data based on coordinates.

## ✨ Features

- 🔍 **Location-based search** for weather updates by city name.
- 🌡 **Current weather** data including temperature, wind speed, and condition.
- 📆 **3-day forecast** with max/min temperature and conditions.
- 🗺 **Interactive Map** using MapKit that updates in real time with the searched location.
- 📍 **CoreLocation support** for fetching latitude and longitude automatically.
- 🚀 Fully asynchronous network calls with `async/await`.
- 🧠 Clean, modular code using the **Model-View-ViewModel (MVVM)** design pattern.
- 🎨 Intuitive and modern SwiftUI design.

## 🧰 Technologies Used
